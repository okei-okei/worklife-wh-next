# Home Background Image Guide

These images are used only by the WorkLife WH homepage scroll background.

## Required Assets

- `hero-desktop.webp` / `hero-mobile.webp`
  - New Zealand sky, coast, city, and open space for the main hero copy.
- `work-home-desktop.webp` / `work-home-mobile.webp`
  - Everyday working and living mood: cafe, workplace, streets, or residential feeling.
- `life-plan-desktop.webp` / `life-plan-mobile.webp`
  - City overview, roads, commuting, and the relationship between jobs and homes.
- `preparation-desktop.webp` / `preparation-mobile.webp`
  - Airport, luggage, passport, suitcase, or practical departure preparation.
- `information-desktop.webp` / `information-mobile.webp`
  - Bright cafe/table/editorial setting for reading useful information.
- `final-desktop.webp` / `final-mobile.webp`
  - New Zealand evening, sea, sky, or calm future-facing landscape.

## Visual Rules

- Keep enough empty space for Japanese copy.
- Avoid logos, readable text, watermarks, and identifiable faces.
- Prefer WebP or AVIF.
- Desktop images should work as wide backgrounds.
- Mobile images should be vertical compositions, not just cropped desktop images.
- Keep the palette close to navy, blue, green, soft blue, soft green, warm sand, and white.
